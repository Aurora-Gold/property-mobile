# Property Portal Mobile

Expo/React Native application planned for phase 2. It will consume the versioned API contract and prioritize discovery, listing details, saves, enquiries, notifications, and owner/agent listing management.

## Development

```bash
npm install
npm start
```

Use `npm run android`, `npm run ios`, or `npm run web` for the corresponding Expo target. The API URL is currently local-development configuration and must become environment-configured before device testing.

See [AGENTS.md](../AGENTS.md) for platform boundaries and [SPEC.md](../SPEC.md) for the mobile delivery phase.
